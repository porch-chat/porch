# Porch brand assets

`porch-chat-icon.svg` is the existing Porch threshold/chat mark reused from the
Porch website and legacy desktop package. It is a separately supplied Porch
brand asset and is not relicensed by the AGPL-3.0-or-later source license.

Stable and Canary intentionally use the same Porch mark. Their distinct product
names, package IDs, protocols, data directories, and Windows identities make
them distinguishable and side-by-side installable without inventing a second
brand.
